DVD Rental AI Prediction

Integrasi Data Warehouse (OLAP) dan Machine Learning untuk Optimasi Inventaris.

Tujuan Proyek

Proyek ini dirancang untuk membantu pemilik toko DVD dalam mengelola stok film secara cerdas. Dengan memanfaatkan data historis dari database Sakila, sistem ini mampu memberikan insight mendalam tentang pola penyewaan pelanggan.

Masalah utama yang diselesaikan adalah "Dead Stock" (stok mati), di mana sistem memprediksi apakah sebuah film baru akan laku (High Demand) atau tidak sebelum stok dibeli.

Python (Django) PostgreSQL Scikit-Learn Chart.js Bootstrap 5

Arsitektur OLAP

Menggunakan tabel fakta (Fact Table) untuk memproses ribuan data transaksi menjadi informasi yang siap dianalisis secara real-time.

AI Prediction

Model Machine Learning (Random Forest/Logistic Regression) yang dilatih untuk mengenali karakteristik film populer.

Fitur Utama Aplikasi

Analytical Dashboard

Visualisasi distribusi rating film dan analisis demand pasar secara dinamis.

Demand Predictor

Input spesifikasi film (durasi, rating, harga) untuk mendapatkan prediksi popularitas.

Automated ETL

Proses Extract, Transform, dan Load data dari database operasional ke database analitik.

Dikembangkan sebagai Proyek Akhir Mata Kuliah Data Science / Data Warehouse.
